# AEO 보고서 (정적 페이지)

`index.html` 한 장이 전부다. 외부 파일을 하나도 안 부른다(폰트·CSS 내장).

**여기서 직접 고치지 마라.** 정본은 Dropbox 의 md 다.

```
0.2_vibe/AEO project/분석_AEO원리와_마롱커버리지_20260814.md   ← 정본
```

## ⚠️ 이건 **대외판**이다

정본 md 안에 `<!--내부--> ... <!--/내부-->` 로 감싼 부분이 있고,
발행할 때 그게 빠진다(재현 명령·파일 경로·DB 위치 등 내부 배관).
**파일을 둘로 만들지 않는다** — 그러면 숫자가 갈라진다.

갱신은 이 한 줄:

```bash
python3 _tools/aeomd2html.py <정본> --external --out index.html
```

`--external` 을 빼먹으면 **내부 경로가 그대로 공개된다.** 반드시 붙인다.
